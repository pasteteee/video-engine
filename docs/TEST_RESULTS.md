ошибки timestamps, низкий FPS, wrap углов, NaN/Inf, вырожденные landmarks.

## Звук

Помимо PCM-тестов выполнены два настоящих интеграционных прогона:
WAV (тишина / тон 150 Hz, 2 s) → FFmpeg/AAC MP4 → FFmpeg PCM → librosa.
Проверены длина всех сигналов, конечность loudness, отсутствие Infinity, отсутствие
F0 на тишине и восстановление F0 150 Hz с допуском 5 Hz.
`tests/test_audio_integration.py`: 2 passed. Вызов subprocess не замокан.
Для воспроизведения: `pip install -e ".[dev,featurebank,test-media]"`.
Интеграционные тесты выбирают ffmpeg из imageio-ffmpeg через FACE_ENGINE_FFMPEG.
В обычном запуске движок использует ffmpeg из PATH либо явно заданный FACE_ENGINE_FFMPEG.

## Внешняя нейросеть и пределы оценки

В репозитории нет вызова LLM: проверены структура JSON, конфигурация и путь данных
до файла. Внешний потребитель не входит в этот репозиторий. Независимая количественная
оценка выполнена для blink-событий на TalkingFace и Eyeblink8. Точность AU по DISFA/BP4D,
демографическая обобщаемость и межъязыковая точность не измерены; эти ограничения
сохраняются в отчёте. Текстовый словарь английский.

## Совместимость

Новые поля добавлены без удаления существующих. Доли жестов при скрытых кистях теперь null, а не 0. Некорректные fps/timestamps теперь
вызывают ValueError. FeatureBank требует равномерную сетку от нуля. Старые pickle-кеши
игнорируются, используется NPZ. Автокорреляция на данных с пропусками изменилась:
теперь Pearson только по наблюдаемым парам. Старые численные результаты могут отличаться.

невалидные release-пороги, one-to-one matching, micro-агрегация, обязательность
всех отчётов и запись фактического EngineConfig в JSON.
