# face-engine

> **Документация для тестирования:** [TESTING.md](TESTING.md) (установка, запуск, тесты, что проверить),
> [docs/METRICS.md](docs/METRICS.md) (каждое значение отчёта: смысл, формула, единицы, оговорки),
> [docs/FEATUREBANK.md](docs/FEATUREBANK.md) (банк из ~30 000 признаков, голос, текст, научные оценки),
> [docs/BEHAVIOR.md](docs/BEHAVIOR.md) (карта поведения: 45 признаков в 8 каналах против личной базы по состояниям, микродёрганья, моменты «лицо первым», данные для оверлея).

Движок, который превращает фото или видео человека в JSON-файл с поведенческими
маркерами лица, головы, взгляда, позы и жестов. Файл рассчитан на чтение
языковой моделью: в нём есть глоссарий полей, сводка по сегментам, лента событий
и короткие выводы на английском.

**Чего движок не делает:** не детектирует ложь, намерения и «настоящие» эмоции.
Метка `expr.anger = 0.7` значит только «конфигурация лица похожа на прототип
выражения гнева». Выводы о манипуляции остаются за человеком или LLM с контекстом.

## Как это устроено

```
фото / видео
   │  детектор лэндмарков (MediaPipe Tasks, заменяемый)
   ▼
FrameObservation: именованные точки лица (35), тела (15), кистей (21)
   │  анализаторы (заменяемые, протокол Analyzer)
   ├─ FaceAnalyzer: выравнивание → измерения → личный базис → AU → выражения, события
   └─ BodyAnalyzer: координаты в ширинах плеч → поза, жесты, самоприкосновения, события
   ▼
Engine → report.json (meta, glossary, baseline, summary, segments, events, frames)
```

### Математика лица

1. **Проекция в канонический каркас.** Жёсткие опорные точки (углы глаз,
   переносица, кончик носа, виски, лоб) выравниваются на каноническое нейтральное
   лицо методом Умеямы (подобие: масштаб + поворот + сдвиг). Поворот даёт позу
   головы (yaw/pitch/roll), а выровненная форма уже не зависит от позы, размера и
   положения в кадре. Единица длины — межзрачковое расстояние (IOD).
2. **Измерения.** С выровненной формы снимаются ~25 геометрических величин:
   высота внутренних и внешних бровей, расстояние между бровями, раскрытие век,
   подъём нижнего века, высота уголков рта, ширина рта, зазор между губами,
   толщина красной каймы, раскрытие челюсти, нос–глаз, положение радужек.
3. **Личный базис.** Нейтраль человека — медиана измерений по 30% самых
   «спокойных» кадров (ближайших к медиане клипа и фронтальных). Можно передать
   отдельное нейтральное фото или видео (`--neutral`). Для одиночного фото без
   нейтрали используется популяционное каноническое лицо, и это помечается в
   `baseline.face.method`.
4. **Отклонения → AU.** Отклонение от базиса, делённое на «полную шкалу»
   (`config.py`), даёт интенсивность 0..1 для 15 прокси FACS action units
   (AU1, 2, 4, 5, 6, 7, 9, 10, 12, 15, 17, 20, 23, 25, 26), отдельно для левой и
   правой стороны там, где это важно.
5. **Интерпретация.** Прототипы выражений по EMFACS (мягкое «И» компонентов),
   презрение как односторонний AU12, улыбка Дюшенна (AU6+AU12) против
   «социальной» (только AU12), асимметрия рта/бровей/глаз, взгляд (поза головы +
   радужки), признак речи по колебаниям губ.
6. **Время.** Сглаживание, моргания и длительные закрытия глаз, события AU и
   выражений с флагом `brief` (короче 0.5 с), кивки и покачивания головой
   (детектор колебаний zigzag), отведение взгляда.

### Математика тела

Все координаты — относительно середины плеч в ширинах плеч (SW), поэтому не
зависят от размера кадра и расстояния до камеры. Признаки: наклон к камере
(`lean_in`), крен плеч, боковой наклон, пожимание плечами, высота кистей,
раскрытость рук, скрещённые руки, сцепленные кисти, касание лица, открытые
ладони (нормаль ладони по лэндмаркам кисти), скорость жестикуляции. События:
жесты, касания лица, скрещённые руки, сдвиги позы, пожимания плечами.

## Карта поведения

```bash
face-engine behavior clip.mp4 -o out/ --transcribe small.en
```

45 признаков (лицо, глаза, голова, тело, руки, голос, речь, несоответствия слов и жестов),
каждый как отклонение от базы того же человека; индекс нагрузки 0–100; hotspot-ы, где
≥3 канала ушли от базы в пределах 5 с; разбор по вопросам; `overlay.json` с зонами и
подписями для рендера; `moments.json` по правилу «лицо первым» (микродёрганья против личного
p95, база отдельно для речи и слушания, проверки качества, кадр «норма для него»). Подробно: [docs/BEHAVIOR.md](docs/BEHAVIOR.md).

## Установка и запуск

```bash
pip install -e ".[mediapipe,dev]"
face-engine models                       # скачать модели MediaPipe (~21 МБ)
face-engine analyze debate.mp4 -o debate.json
face-engine analyze debate.mp4 --neutral calm_face.jpg --segment 10 --sample-fps 15
face-engine analyze photo.jpg -o photo.json
face-engine demo -o demo.json            # синтетический клип, без детектора
```

Полезные флаги: `--frames-fps 5` (сколько покадровых строк в секунду писать,
0 — не писать), `--max-seconds`, `--no-body`, `--save-landmarks lm.npz`
(сохранить вывод детектора и потом перезапускать анализ без него:
`face-engine analyze lm.npz`).

Для Linux без GPU MediaPipe нужен `libegl1` и `libgles2`.

## Визуальная проверка

```bash
face-engine visualize debate.mp4 -o viz/      # overlay.mp4, timeline.png, moments.png, report.json
face-engine visualize photo.jpg -o viz/       # overlay.png
```

Оверлей рисует точки лица, скелет и кисти, а справа панель с AU, выражениями,
позой головы и активными событиями. Таймлайн показывает тепловую карту AU,
выражения, позу головы с кивками, моргания и флаги тела по времени.

Что показали визуальные тесты и что исправлено:
* при сильном наклоне головы (±45°) масштаб лица «плыл» на 10–15% и рождал
  ложное «отвращение» — масштаб теперь привязан к расстоянию между глазами;
* при повороте и наклоне головы 2D-детектор сжимает черты — нейтраль теперь
  зависит от позы (медианы по бинам позы + квадратичная модель);
* на морганиях ложно срабатывал AU6 — веки игнорируются рядом с морганием;
* широкая улыбка давала «отвращение» — прототипы печали, гнева, отвращения
  подавляются улыбкой;
* события AU не выдаются, пока лицо повёрнуто слишком сильно.

## Формат отчёта

| ключ | что внутри |
|---|---|
| `disclaimer` | как читать файл и чего он не утверждает |
| `meta` | файл, fps, размер, число кадров, детектор |
| `glossary` | описание каждого признака и единиц |
| `baseline` | метод и значения личной нейтрали лица и тела |
| `summary` | сводка по всему клипу, счётчики событий, `highlights` (готовые фразы) |
| `segments` | окна по N секунд: AU, доминирующее выражение, моргания, взгляд, речь, жесты, поза; `notable_vs_clip` — чем окно отличается от среднего по клипу |
| `events` | лента событий с началом, концом, пиком и номерами кадров видео (`frame_start`, `frame_end`): `blink`, `action_unit`, `expression`, `smile` (Дюшенн/асимметрия), `gaze_averted`, `head_nod`, `head_shake`, `gesture`, `face_touch`, `arms_crossed`, `hands_joined`, `open_palms`, `shrug`, `posture_shift` |
| `frames` | покадровые значения всех признаков (с прореживанием) |

## Расширение и гибрид

Детектор и анализаторы заменяемы:

* `sources.LandmarkSource` — любой детектор, который выдаёт именованные точки
  (`topology.py`). Для другого детектора нужен только маппинг индексов.
* `analyzers.base.Analyzer` — любой анализатор с методами `analyze` и
  `summarize`. Готовую библиотеку (например, блендшейпы MediaPipe или другой
  AU-детектор) можно обернуть в анализатор и запускать рядом со своими, чтобы
  сравнивать или комбинировать.

## Тесты

```bash
pytest                                    # актуальные результаты: docs/TEST_RESULTS.md
FACE_ENGINE_SAMPLES=dir_with_portrait_jpg pytest tests/test_mediapipe_integration.py
```

Синтетический генератор (`sources/synthetic.py`) двигает точки канонического лица
на известные величины («улыбка 1.0», «подмигивание», «кивок» и т. д.) при разных
позах головы, шуме и индивидуальной морфологии, поэтому тесты проверяют и
инвариантность к позе, и восстановление интенсивностей, и личный базис.

## Ограничения

* Пороги и «полные шкалы» AU — эвристики из диапазонов FACS, их нужно
  откалибровать на размеченных данных (например, DISFA/BP4D для исследований).
* Глубина (z) у MediaPipe оценочная: при повороте головы больше ~20° асимметрия и
  часть AU становятся менее надёжны (`face.reliability`).
* Автоматический базис — это «типичное» лицо человека в клипе. Если человек
  улыбается весь ролик, улыбка станет нейтралью; для таких случаев есть `--neutral`.
* Во время речи AU рта (25, 26, 10, 23) шумят; смотрите на `mouth.speaking`.
* Один человек в кадре; при нескольких берётся первое лицо и первая поза.


## Аудит и расширение (24 ноября 2026)

[Исследование и путь данных до LLM](docs/RESEARCH_AND_AUDIT.md),

`blink_release_closure=0.25` повышает precision ценой recall; default остаётся None.
