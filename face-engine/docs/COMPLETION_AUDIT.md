## Результаты

- Полный прогон: 179 passed in 8.93s, без пропусков.
- TalkingFace, 61 моргание: P=0.9298, R=0.8689, F1=0.8983 по timestamps 25 FPS.
- Eyeblink8, 408 морганий, 70 992 размеченных кадра: P=0.9402, R=0.8480, F1=0.8918.
- Исходные default-события подтверждены повторным анализом сохранённых NPZ текущей версией.
- Сравнение release=0.25: на шести отложенных роликах F1=0.8588 против 0.8920 у default.
  Поэтому default сохранён; optional-режим явно описан как обмен recall на precision.

## Пределы результата

Это инженерный аудит и проверка работоспособности всех семейств признаков по плану,
плюс независимая количественная оценка событий морганий. Точность AU/жестов на
независимой разметке и обобщаемость на все группы людей не установлены. Движок
сохраняет эвристические AU, популяционный/автоматический базис и ограничения
одного человека в кадре; английский словарь не анализирует русский текст.
Нерегулярные timestamps требуют предварительной обработки; Eyeblink8 оценён
по исходным frame IDs при FPS контейнера, TalkingFace — дополнительно по timestamps.
Внешний LLM-клиент отсутствует, поэтому ответ сторонней LLM не проверялся.

Все запланированные инженерные проверки и прогоны данных завершены; фоновых
процессов этой задачи не осталось. Дальнейшая калибровка AU, eye-tracker gaze,
клинические выводы и обучение LLM не являются подтверждёнными результатами этой работы.
