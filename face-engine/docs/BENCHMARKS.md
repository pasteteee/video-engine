# Независимая оценка морганий

## Данные и протокол

Источник: [автор разметки](https://www.blinkingmatters.com/research).
TalkingFace: 5000 кадров, один человек, 61 blink ID. На странице автора для данных
указана GPL3; исходные архивы сохраняются только в игнорируемой .test-assets,
не включены в исходники проекта. Скрипты оценки написаны самостоятельно.

Мы оцениваем объединённый blink ID, а не отдельные глаза: это соответствует
существующему событию blink движка. Интервалы включают оба крайних кадра.
События сопоставляются взаимно однозначно при IoU > 0.2 с максимальным числом
совпадений; лишние предсказания считаются FP. Отсутствие детекции лица не удаляет
кадры из теста. Значения не сопоставимы напрямую с per-eye таблицами автора.
Пороги движка на этой выборке не оптимизировались.

## TalkingFace: результат

| Временная шкала | TP | FP | FN | Precision | Recall | F1 |
|---|---|---|---|---|---|---|
| исходный AVI, metadata 30 FPS | 54 | 4 | 7 | 0.9310 | 0.8852 | 0.9076 |
| независимый файл timestamps, 25 FPS | 53 | 4 | 8 | 0.9298 | 0.8689 | 0.8983 |

Основной результат — вторая строка: timestamps имеют шаг 0.04 s, а AVI сообщает
30 FPS. Скорость временного сглаживания и длительности событий зависят от FPS,
поэтому одинаковые кадры дают немного разные события. Результат с 30 FPS
сохранён как диагностика расхождения контейнера и шкалы аннотации.

Ошибки включают одиночные threshold-кадры с недостаточным IoU относительно полного
движения век, пропуски при улыбке и длительное закрытие, объединяющее несколько
размеченных интервалов. Создан и просмотрен контактный лист error-moments.png.
Пороги не изменены ради улучшения конкретного benchmark; нужны отдельные train/validation
данные и независимый test, прежде чем менять детектор.

## Воспроизведение

После самостоятельного получения архива talkingFace.zip с указанной страницы:

```powershell
face-engine analyze .test-assets/talkingFace/talking.avi --no-body --save-landmarks .test-assets/talkingFace/landmarks.npz -o .test-assets/talkingFace/report.json
.venv/Scripts/python examples/benchmark_blinks.py .test-assets/talkingFace/landmarks.npz .test-assets/talkingFace/talking.tag .test-assets/talkingFace/talking.txt -o .test-assets/talkingFace/benchmark.json
```

В benchmark.json записаны SHA256 разметки/временных меток и протокол.
Оценщик src/face_engine/evaluation.py отдельно принимает report.json и .tag.
Тесты оценщика проверяют повторные детекции, взаимно однозначное сопоставление,
переуступку совпадения, строгую границу IoU, пустые ответы и соседние blink IDs.

## Ограничения

Один человек не доказывает обобщаемость по людям, камерам, очкам или освещению.
Blink F1 не измеряет качество AU, взгляд, эмоции или намерения. Eyeblink8 полностью обработан; результаты приведены ниже.


## Eyeblink8: зафиксированный протокол до результатов

Архив получен с той же страницы автора. Проверка файлов обнаружила 408 blink ID,
70 992 размеченных кадра и неполную разметку восьми видео. Полный видеопоток
сохраняется для анализа; предсказанные интервалы обрезаются/разделяются по
непрерывным размеченным участкам. Неизвестные кадры исключаются из оценки.

Метки времени содержат нерегулярные интервалы, включая многосекундные разрывы.
Текущий Engine работает с равномерной сеткой; в этом benchmark явно используется
30 FPS контейнера и сравнение исходных frame IDs, без утверждения точности физического
времени. Это ограничение протокола, а не автоматическое исправление timestamp-файлов.
Временная шкала TalkingFace отдельно скорректирована по его равномерным меткам.

Команда оценки отдельного Eyeblink8 отчёта:
`python -m face_engine.evaluation report.json clip.tag --allow-partial-annotation -o evaluation.json`.
Все восемь видео обработаны. Сохранены landmarks.npz и report.json по каждому ролику.


## Проверка улучшения границ blink (эксперимент)

На момент выбора варианта просмотрены TalkingFace и итог первого Eyeblink8 ролика (1).
Вариант: high=существующий blink_closure=0.5, low=0.25 (половина high),
событие — связный low-интервал с хотя бы одним high-кадром. Пропуски разрывают
интервалы, low-only движения не принимаются. Новый параметр blink_release_closure
по умолчанию None: пока рабочий детектор сохраняет прежнее поведение.

Development TalkingFace (25 FPS): TP=51, FP=0, FN=10, P=1.0, R=0.8361, F1=0.9107.
Это обмен полноты на precision, не безусловное улучшение. Результат baseline:
TP=53, FP=4, FN=8, F1=0.8983. Подбор сетки low-порогов не проводился.

Для проверки переноса фиксируются остальные шесть Eyeblink8 роликов
11, 2, 3, 4, 8, 9 до просмотра их event-метрик. Ролики 1 и 10 будут диагностическими,
а не независимым test после выбора варианта. Это не subject-disjoint эксперимент:
разные ролики могут содержать одних людей. Решение по default приведено в итогах ниже.


Для воспроизведения полного прогона и сравнения на одинаковых landmarks:

```powershell
.venv/Scripts/python examples/run_blink_dataset.py .test-assets/eyeblink8
.venv/Scripts/python examples/evaluate_blink_dataset.py .test-assets/eyeblink8 -o .test-assets/eyeblink8-baseline.json
.venv/Scripts/python examples/run_blink_dataset.py .test-assets/eyeblink8 --release .25
.venv/Scripts/python examples/evaluate_blink_dataset.py .test-assets/eyeblink8 --report-name report-hysteresis.json -o .test-assets/eyeblink8-hysteresis.json
```

Повторный вариант берёт сохранённые NPZ, а не повторно запускает MediaPipe.
Агрегатор требует отчёт для каждой .tag-аннотации и не пропускает неудачные ролики.
Micro P/R/F1 вычисляются из суммы TP/FP/FN, а не усреднением F1 роликов.


## Итог Eyeblink8

Обработаны все восемь видео: 71 356 декодированных кадров, из них 70 992 размечены,
408 blink ID. Счётчик кадров AVI местами включает недекодируемый хвост; оценка
проверяет, что каждый размеченный frame ID присутствует в отчёте.

|---|---|---|---|---|---|---|
| Default | 346 | 22 | 62 | 0.9402 | 0.8480 | 0.8918 |
| release=0.25 | 309 | 1 | 99 | 0.9968 | 0.7574 | 0.8607 |

| Ролик | Default F1 | release=0.25 F1 |
|---|---|---|
| 1 | 0.7714 | 0.7333 |
| 10 | 0.9504 | 0.9254 |
| 11 | 0.9070 | 0.8861 |
| 2 | 0.9711 | 0.9136 |
| 3 | 0.8000 | 0.7000 |
| 4 | 0.7778 | 0.7600 |
| 8 | 0.8667 | 0.9474 |
| 9 | 0.9351 | 0.9211 |

На шести заранее отложенных роликах (11, 2, 3, 4, 8, 9): default TP=252,
FP=15, FN=46, F1=0.8920; release=0.25 TP=225, FP=1, FN=73, F1=0.8588.
Падение F1 подтверждается за пределами development TalkingFace.

**Решение:** default остаётся `blink_release_closure=None`. Значение 0.25 доступно
как явный режим с повышенной precision и потерей recall; оно не рекомендуется
как общее улучшение. Других low-порогов после просмотра результатов не подбирали.

Результаты и хеши: .test-assets/eyeblink8-baseline.json,
eyeblink8-hysteresis.json и eyeblink8-reserved6.json. События/summary baseline
текущей версии совпали по значениям JSON с исходным полным прогоном
до введения experimental-параметра. Повторно выполнена только геометрическая
обработка из NPZ, без повторной детекции MediaPipe.

Покрытие этой проверки: blink-события. Эти числа не являются точностью AU,
оценкой личности, намерений или эмоций. Различия протокола и FPS не позволяют
напрямую сравнивать результат с per-eye таблицами автора набора.
