# Real Story: оформление YouTube-канала

Все файлы лежат в этой папке. YouTube Studio → **Настройка канала** → вкладка **Брендинг** / **Основные сведения**.

| Что | Файл | Куда | Требования YouTube |
|---|---|---|---|
| Фото профиля | `avatar_800.png` | Брендинг → Фото профиля | ≥ 98×98, PNG/JPG, до 4 МБ, показывается кругом |
| Баннер | `banner_2560x1440.jpg` | Брендинг → Баннер | 2048×1152+, до 6 МБ; на всех устройствах видна центральная зона 1546×423 |
| Водяной знак | `watermark_150.png` (или `watermark_300.png`) | Брендинг → Водяной знак, «В конце видео» или «Всё видео» | 150×150, PNG с прозрачностью, до 1 МБ |
| Фон конечной заставки | `endscreen_1920x1080.png` | Движок вставляет его в последние 20 с серии; элементы ставятся в Studio → Редактор → Конечная заставка | Расположение зон: `previews/endscreen_guide.jpg` |
| Логотип для превью/постов | `logo_wordmark.png` | Сообщество, сторонние площадки | Прозрачный фон, только на тёмном |

Как всё выглядит на ПК, телефоне и ТВ: `previews/youtube_pack_preview.jpg`.

## Конечная заставка (Studio → Конечная заставка)
- **Видео 1**: «Самое подходящее для зрителя», большой блок слева, по зелёной рамке из `endscreen_guide.jpg`.
- **Видео 2**: плейлист серии или «Последнее загруженное», справа сверху.
- **Подписка**: круг справа снизу.

## Описание канала (Основные сведения → Описание, ~700 знаков)

```
True stories, shown with the original records.

Real Story retells real events through the material they left behind: NASA photo captions, mission audio, ship logs, satellite tracks, scientific data. No re-enactment pretending to be footage. When we show something nobody filmed, it is labelled as an illustration.

Every episode answers one question with the primary sources on screen: what happened to Gemini 8, how a bird flew 13,560 km without landing, what the Bloop really was.

New episodes and Shorts every week. Sources are listed under each video.

Business: [email]
```
